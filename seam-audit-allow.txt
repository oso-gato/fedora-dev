# WHAT BELONGS HERE, AND WHAT DOES NOT.
# Only the ADVISORY classes are allowlistable — a stubbed seam can be entirely correct, because you
# cannot run a model, a network call or a real host inside a unit test. Add a line here when the stub is
# genuinely the only option, WITH a reason.
#
# The GATING class — a flag `gh` does not accept — is NOT allowlistable and never will be. `gh` rejects
# such a call before any network request, so the call returns nothing and any stub that accepts it is
# certifying code production cannot run. There is no legitimate instance of that.
#
# BEFORE ADDING A LINE, ask the question the audit is really posing: is this seam stubbed because the
# real thing CANNOT run here, or merely because stubbing was easier? Four defects on 2026-07-29 lived in
# the second case, each behind a green suite. An allowlist that answers "easier" is how this check
# becomes decoration.
